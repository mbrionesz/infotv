# XuperTizen 0.8.9 beta

- Elegir una categoría o un filtro ya no vuelve automáticamente a la portada antigua si falla la consulta. Se conserva la selección y se ofrece Reintentar. Una categoría cuyo estante falla se consulta por el endpoint alternativo conservando su mismo ID.
- Los favoritos de películas y series guardan título, portada y tipo localmente, y siguen disponibles al reiniciar aunque el catálogo inicial no contenga ese título.
- Principal muestra filas separadas: Mi lista para favoritos y Seguir viendo para episodios/minutos pendientes, además de Para descubrir. El mando permite desplazarse entre las filas y abrir Ver todo.
- Mi lista tiene paginación y un máximo de 200 títulos. Quitar un favorito no elimina el progreso.

Conserva los 17 DNS y los motores de reproducción de la versión anterior. Pruebas de categorías fallidas, reproducción MP4/MPEG-TS, favoritos después de reiniciar y recuperación real del episodio/posición, con datos de laboratorio. Pendiente confirmar Serie Turquía con el portal desde el televisor.

Instala el WGT con Apps2Samsung.
